# Islom — Portfolio

A responsive, accessible portfolio built with semantic HTML, CSS, and vanilla JavaScript. No dependencies or build step.

## Run locally

From this directory, run `python3 -m http.server 8000`, then visit port 8000 in your browser.

## Deploy on GitHub Pages

Open **Settings → Pages → Build and deployment → Source: Deploy from a branch**. Select **main** and **/ (root)**, then **Save**. After deployment, the site is available at https://madebyislom.github.io/portfolio1/.

## Personalize before sharing

- Replace the three illustrative project concepts with your actual projects, screenshots, demo URLs, and repository URLs.
- Add your email, LinkedIn URL, and résumé URL in `index.html`. Confirm the GitHub profile URL.
- Replace the learning timeline with your real education dates and achievements.
- Add your Formspree endpoint to the form's `action` attribute. Until configured, the form explicitly reports that delivery is unavailable and never claims a message was sent.
- Replace the social preview image if desired. All included SVG illustrations are original placeholders.

## Checks

Use keyboard navigation, both themes, and narrow and wide screens. Verify links and configured form delivery before sharing. Run Lighthouse against the deployed site; a score is not guaranteed across devices or hosting conditions.
